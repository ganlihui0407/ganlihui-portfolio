# Gan Li Hui Portfolio

A personal software engineering portfolio website showcasing my academic journey, technical skills, certifications, and software development projects.

I am a Bachelor Degree in Software System Development student at Tunku Abdul Rahman University of Management and Technology (TAR UMT). The site presents my work for internship applications, with a focus on software engineering, web applications, and AI application development.

- Responsive portfolio website
- Personal introduction
- Education background
- Technical skills showcase
- Project case studies
- Certificate showcase
- Resume download
- Contact information

## Getting Started

Clone the repository, install dependencies, and start the development server:

```bash
git clone https://github.com/ganlihui0407/ganlihui-portfolio.git
cd ganlihui-portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
